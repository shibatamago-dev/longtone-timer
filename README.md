# ロングトーン／呼吸タイマー

調を選ぶだけで、呼吸 → ロングトーン → クールダウンの日課メニューをテンポ60で案内するタイマーです。

公開ページ： https://shibatamago-dev.github.io/longtone-timer/

## 使い方

1. 調を選ぶ（12の調、既定はB♭調）
2. メニューを選ぶ（はじめて約5分／ふだん約10分／じっくり約15分）
3. スタート。ロングトーンは選んだ調の主音から半音ずつ下がり、1オクターブ下の主音まで届きます

- 吹く／休むの長さはチップで調整できます（メニューごとにブラウザへ保存）
- 画面は左に「いま」、右に「つぎ」を常時表示します
- ブラウザだけで動作し、設定の保存はブラウザ内（localStorage）だけです

## 注意

めまい・しびれ・息苦しさが出たら、すぐに中止してください。長さを競うためのものではありません。
